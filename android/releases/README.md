## رفعه إلى Google Drive

1. ارفع ملف APK فقط إلى Google Drive.
2. اجعل صلاحية الملف: **أي شخص لديه الرابط — مشاهد**.
3. انسخ معرّف الملف `FILE_ID` من رابط Drive.
4. استخدم رابط التنزيل المباشر التالي في زر الموقع:

```text
https://drive.google.com/uc?export=download&id=FILE_ID
```

مثال HTML:

```html
<a href="https://drive.google.com/uc?export=download&id=FILE_ID">
  تحميل مساعد الصيانة للأندرويد
</a>
```

قد يعرض Google Drive صفحة تأكيد أمان للملفات الكبيرة حسب سياساته أو حد التنزيل.

## التحقق قبل النشر

قارن بصمة SHA-256 مع الملف `SHA256SUMS.txt`. يجب أن تتطابق البصمتان تماماً.

عند إصدار تحديث مستقبلي:

1. ارفع `versionCode` في `pubspec.yaml`، مثل `1.0.1+2`.
2. استخدم مفتاح التوقيع نفسه دائماً حتى يقبل Android التحديث.
3. لا ترفع `key.properties` أو ملف التوقيع `.jks` إلى Git أو Drive.
4. قبل النشر، تأكد أن بصمة شهادة APK تطابق البصمة المسجلة أعلاه.
